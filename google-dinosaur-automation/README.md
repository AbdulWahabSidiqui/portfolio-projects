# 🦖 Google Dinosaur Automation

A Python automation project that plays the Chrome T-Rex game by analyzing screen pixels.

## How It Works

The program:

1. Captures a portion of the screen using Pillow.
2. Scans the pixels for dark objects.
3. Detects approaching obstacles.
4. Uses PyAutoGUI to press Space.
5. Makes the T-Rex jump automatically.

## Technologies

- Python
- PyAutoGUI
- Pillow
