# Ecommerce Website

A simple eCommerce website built with Flask, SQLite, and Stripe Checkout.

## Features

- User registration and login
- Password hashing
- Product listing
- Shopping cart
- Add and remove products
- Cart total calculation
- Stripe Checkout
- Successful payment page
- Protected checkout for logged-in users

## Technologies

- Python
- Flask
- Flask-SQLAlchemy
- Flask-Login
- SQLite
- Bootstrap
- Stripe API
