# ☕ Cafe & WiFi Finder

A Flask web application that helps users discover cafes with WiFi, power sockets, and great coffee.

Built as part of Angela Yu's 100 Days of Code course and enhanced with a responsive Bootstrap interface.

## Features

- View all cafes
- Add new cafes
- Store cafe information in SQLite
- Responsive Bootstrap design
- Google Maps links for every cafe

## Tech Stack

- Python
- Flask
- Flask-WTF
- SQLAlchemy
- SQLite
- Bootstrap 5
- HTML5
- CSS3

## Project Structure

```
Cafe Website/
│
├── static/
├── templates/
├── forms.py
├── models.py
├── main.py
├── cafes.db
└── requirements.txt
```

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/cafe-website.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
